Counterexamples to Conjecture 25 and Remark 6 of Garrappa–Gerhold–Popolizio–Simon: Global modulus lower bounds in arXiv:2410.11852v4

Haobo Ma, Wenlin Zhang

论文

马浩博与张文林研究两类复函数：在复数点处的模，是否总不小于去掉虚部后所得实数点处的函数值。他们对一个猜想给出整族反例，对另一个问题给出简明例子，并注明后者此前已有否定答案。

第一类是推广指数函数的双参数 Mittag–Leffler 函数。其幂级数把 zᵏ/Γ(αk+β) 相加；Γ 推广了阶乘，α、β 决定系数，Γ 在非正整数处的倒数按零计。α 为正时，级数在整个复平面收敛。固定参数后简称函数为 E，所问的是 |E(z)| ≥ E(Re z)：左边取复数的模，右边只是去掉虚部后的实轴函数值，不取绝对值。指数函数处处取等号，因此考察其推广能否保持这种比较很自然。

Garrappa、Gerhold、Popolizio 和 Simon 猜想：当 1 < α < 2、β ≥ 0 时，全局比较成立恰好对应 α−1 ≤ β ≤ α，也等价于倒数函数在正实轴上完全单调。“完全单调”指正的光滑函数，其一阶导数非正、二阶导数非负，依次交替。前四位作者已证明倒数函数在上述区间具有此性质。本文否定的是从实轴规律推到复平面模下界的关联，而非那项已证定理。

主要结果覆盖每个介于一与二之间的 α。在 β = α−1 时，沿左半平面内一条适当射线，任意远处仍有反例。关键是展开式缺少首项：在负实轴方向附近，逆一次项系数为零，主项变成 C/z²，且 C 为正。作者通过 Hankel 围道积分导出此式，把误差控制为常数乘 |z|⁻³。比较 −r 与 −r+irt，其中 t 是适当的固定正数；二者实部相同，后者离原点更远，故主项的模缩小为前者的 1/(1+t²)。r 足够大时，较低阶误差无法抵消差距。

问题不只出在端点。固定一个足够远的反例点后，由关于 β 的连续性，失败在闭区间 [α−1, α−1+ε] 内保持，其中 0 < ε < 1。故猜想区间内部也有反例，同时倒数仍完全单调。前人结果还表明，将 E 缩放至原点值为一后取对数，所得函数仍具有 Bernstein 性质：非负、光滑，导数完全单调。这两种实轴性质都不足以保证全局下界。所选复数点和区间可以随 α 改变。

有限证书取 α = 3/2、β = 1/2、z = −115+10i。作者将级数前六十四项拆成两个有理系数多项式，其中一个乘以 1/√π，再用该常数的有理区间和精确算术夹住部分和。递推关系把剩余奇、偶尾项分别控制为几何级数。复数处的模小于 0.0000110000004，实轴值却大于 0.0000299999996。这是控制了无限余项的明确估计，不只依赖小数近似。

第二个问题涉及同样由处处收敛幂级数定义的 Kummer 函数 M(a,b,z)，其中 b = a−d，a、d 为正，b 不得为非正整数。本文将较早的小虚数反例归于 Pudim AI Project 二〇二六年六月十四日的文稿。作者另取 a = 1/2、d = 2，逐项约分得到 M(1/2,−3/2,z) = exp(z)(1−4z/3+4z²/3)。在 z = 1/2+i√2/2 处，二次多项式为零；在其实部 1/2 处却为 2/3。因此复数处的模为零，拟议下界却为正。

围道、连续性及全系数论证属于书面证明；具体证书依靠精确有限算术和尾项界。文稿报告的 Lean 陈述覆盖：以函数符合原级数为条件的参数族、纳入级数定义与猜想等价关系的否定结论，以及 Kummer 全称命题的否定。这些陈述本身不等于认证每个分析步骤；一百零一次补充系数检查也不能代替全指标恒等式。端点上的无界反例射线推翻了把“某个有界闭区域外成立”的旧结论延伸到端点的说法，但内部反例仍与原来排除端点的版本相容。已有右半平面下界不受影响；完整参数分类，以及零点、凸性、广义余弦常数和 α ≥ 2 的相关问题，均未在此解决。
